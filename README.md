# Saeid Resume Website

رزومه شخصی و پورتفولیوی Saeid Naghpour برای GitHub Pages.

## فایل‌ها
- `index.html` محتوای سایت
- `style.css` طراحی و ظاهر سایت

## شخصی‌سازی لینک‌ها
در `index.html` این موارد را با لینک واقعی خودت جایگزین کن:

- `YOUR_LINKEDIN_URL`
- `YOUR_TELEGRAM_URL`
- `YOUR_X_URL`
- `YOUR_PROJECT_URL`

## انتشار روی GitHub Pages
Repository را با نام `realsaeid.github.io` بساز و فایل‌های `index.html` و `style.css` را در ریشه Repository قرار بده.
سپس از Settings → Pages، گزینه Deploy from a branch و Branch اصلی را انتخاب کن.
